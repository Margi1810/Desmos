# Features

- Plot supported functions of `x`, including trigonometric functions, roots, logarithms, powers, and constants such as `pi` and `e`.
- Accept expressions with or without the `y =` prefix.
- Zoom, pan with Matplotlib's navigation toolbar, and reset the viewport.
- Add and remove equations, clear all equations, and skip undefined/non-finite sample points.
- Validate expressions with an AST allowlist rather than evaluating arbitrary Python code.

Supported equations are explicit functions `y = expression`; implicit equations and parametric curves are not supported.
